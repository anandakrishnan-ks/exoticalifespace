# Brand Lumina

Create a premium, elegant, modern website using all the information and content provided in the project.

Overall Design Direction

Create a luxury, high-end, editorial-style website with a strong minimalist aesthetic.

Keep the design clean, sophisticated, spacious, and visually refined.

Use the exact same logo that has been uploaded. Do not redesign, recreate, alter, or replace the logo.

Build a strong visual identity around the existing logo, using complementary typography, spacing, colors, and imagery.

Avoid generic SaaS-style layouts, excessive cards, unnecessary gradients, clutter, or overly rounded UI elements.

The website should feel like it was designed by a professional premium branding and web-design agency.

Typography

Use premium designer/editorial fonts with a sophisticated combination of serif + modern sans-serif typography.

Use a distinctive elegant font for major headings and a clean, highly readable font for body text.

Create a clear typography hierarchy with large, confident headlines and generous spacing.

Make typography a major part of the visual identity.

Hero Section

Create a full-width cinematic hero banner using a premium, high-resolution image relevant to the business.

Large elegant headline

Short supporting description

Refined CTA buttons

Minimal navigation

Strong contrast between text and background

Subtle animations when the page loads

Use a premium image treatment rather than a generic stock-photo appearance.

The hero should immediately communicate luxury, quality, trust, and professionalism.

Premium Imagery

Use high-quality, editorial-style images throughout the website.

Large architectural/lifestyle/product imagery

Sophisticated compositions

Consistent visual treatment

Avoid cheap-looking or generic stock images

Use large image sections instead of filling the page with small cards.

Where appropriate, use cinematic banners and full-width visual sections.

Parallax & Motion

Implement subtle premium parallax effects throughout the website:

Hero background parallax

Image-section parallax

Smooth scrolling

Gentle reveal animations

Text/image fade and slide-in animations

Subtle hover interactions

Image scale effects on scroll

Animations should feel smooth, slow, premium, and intentional. Do not over-animate the website.

Navigation

Create a minimal, elegant navigation bar:

Use the uploaded logo

Keep navigation clean and spacious

Sticky navigation on scroll

Add a subtle background/transparency transition when scrolling

Include a refined mobile navigation menu

Use understated hover animations.

Layout

Use an editorial / luxury brand layout rather than a conventional template.

Mix:

Full-width image sections

Large typography

Asymmetrical layouts

Generous whitespace

Overlapping image/text compositions

Full-bleed banners

Minimal content cards where genuinely useful

Carefully aligned grids

Avoid making every section look identical.

Sections

Use the information already provided to determine the appropriate sections and structure. Present the content in a visually compelling way rather than simply placing text into standard website blocks.

For important sections:

Use strong visual storytelling

Highlight key information using typography

Combine text with premium imagery

Use elegant transitions between sections

Create clear CTAs throughout the site.

Color System

Create a restrained luxury color palette based on the uploaded logo and existing brand identity.

Use:

Neutral backgrounds

Sophisticated typography colors

One restrained accent color

Strong contrast

Plenty of whitespace

Avoid excessive colors.

Product / Service Presentation

Where products or services are listed:

Use elegant editorial layouts

High-quality imagery

Minimal descriptions

Sophisticated hover interactions

Avoid generic ecommerce card grids unless they genuinely improve usability.

Footer

Create a premium, spacious footer containing:

Logo

Important navigation

Contact information

Social links

CTA

Copyright information

Keep the footer visually consistent with the rest of the website.

Responsive Design

The website must be fully responsive and polished across:

Desktop

Laptop

Tablet

Mobile

Pay special attention to mobile typography, image cropping, spacing, navigation, and animation performance.

Technical Quality

Use clean, maintainable components.

Ensure excellent spacing and alignment.

Optimize images and animations for performance.

Use smooth transitions without compromising page speed.

Ensure accessibility and readable contrast.

Make buttons and interactive elements feel polished.

Avoid unnecessary dependencies and visual clutter.

Final Visual Goal

The final result should feel like a premium luxury brand website — elegant, minimal, cinematic, sophisticated, and highly polished.

Think high-end architecture / interior-design / luxury editorial websites rather than a generic business template.

Prioritize:
Premium visuals → Typography → Whitespace → Editorial layouts → Subtle motion → Strong branding → Usability.

Most importantly, use the uploaded logo exactly as provided and build the entire visual language around it.
