# Exotica Lifespace premium website

## Outcome
Build a complete one-page Exotica Lifespace website at `/` using the supplied company copy, structure, addresses, and exact uploaded logo. The experience will feel like a high-end architecture editorial: cinematic imagery, strong serif-led typography, restrained brand color, generous whitespace, and measured motion.

## Visual direction
- Use the uploaded logo unchanged in the navigation and footer; derive the favicon from that same file without altering the displayed logo.
- Build the palette around the logo’s turquoise accent and deep plum-charcoal, balanced with warm white and neutral stone surfaces.
- Pair an elegant editorial serif for display text with a clean contemporary sans-serif for body copy.
- Generate a cohesive set of premium architectural images for the hero, about composition, service stories, expertise, and project gallery. Keep imagery bright, authentic, Kerala-relevant, and consistently art-directed rather than stock-like.
- Use asymmetrical grids, full-bleed image bands, overlapping editorial compositions, fine rules, and restrained square-cornered controls.

## Page structure
1. Sticky transparent navigation with compact logo, section links, consultation action, and full-screen mobile menu.
2. Full-width cinematic hero with the supplied brand promise, location/service summary, two actions, parallax depth, and subtle entrance motion.
3. Slim project-type credibility strip: Residential, Commercial, Retail, Hospitality.
4. About section using the supplied design-build positioning and an offset large-image composition.
5. Six services presented as an editorial numbered index with supporting imagery and concise supplied descriptions.
6. Four-stage process with a horizontal desktop sequence and vertical mobile treatment.
7. Featured expertise and project gallery using large, varied imagery rather than generic cards.
8. Why Exotica section covering all six supplied strengths and the project-partner statement.
9. Dark vision banner with the supplied vision and brand promise.
10. Contact section with consultation form and both supplied addresses; omit phone, email, WhatsApp, and social destinations because no verified details were provided.
11. Spacious branded footer with navigation, services, addresses, CTA, and copyright.

## Interaction and responsive behavior
- Add native smooth scrolling, sticky-header transparency changes, section reveal animations, restrained image scaling, and lightweight scroll-based parallax.
- Respect reduced-motion preferences and keep effects subtle on mobile for performance.
- Ensure mobile navigation, typography, image crops, forms, and all calls to action remain clear and accessible.
- Add semantic headings, labels, image alt text, keyboard focus states, and route-specific social metadata.

## Technical details
- Keep the implementation frontend-only; the enquiry form will validate and show a clear confirmation state without storing or sending submissions.
- Create focused React sections and small reusable controls, with all visual roles defined as semantic tokens in the global design system.
- Use the existing TanStack page structure and no unnecessary dependencies.
- Validate the finished page in desktop and mobile browser sizes, including menu, navigation, form behavior, image loading, motion, overflow, and contrast.
